# 日本語ノート — JLPT N5 · 한 줄 일기

세온 님을 위한 일본어 공부 웹앱입니다. 외부 라이브러리나 CDN 없이 `index.html` 한 파일로 동작하고, 학습 기록은 브라우저 `localStorage`에 저장됩니다.

## 화면

| 탭 | 내용 |
| --- | --- |
| **오늘** | 연속 학습일, 오늘의 체크리스트(가나·단어·회화), 5분 추천 루틴, **한 줄 일기(ひとこと日記)** |
| **가나** | 히라가나·가타카나 46음 + 탁음·요음 표, 헷갈리는 가나 퀴즈, 손가락 따라 쓰기 패드 |
| **단어** | JLPT N5 단어·한자 131개, 카테고리 필터, 후리가나/로마자 토글, 플래시카드, 4지선다 퀴즈 |
| **회화** | N5 문법 15개 + 일상·여행 회화 48문장, JLPT 미니 퀴즈 |
| **복습** | 오답노트, ★ 즐겨찾기, 학습 통계, JSON 백업/복원 |

## 홈 화면에 추가 (안드로이드 크롬)

1. 크롬에서 이 페이지를 엽니다.
2. 오른쪽 위 ⋮ → **홈 화면에 추가**.
3. 아이콘을 누르면 주소창 없이 앱처럼 전체 화면으로 열립니다.

`manifest.json`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`가 함께 배포되어 아이콘과 전체 화면 표시에 쓰입니다.
`index.html`만 따로 내려받아 파일로 열어도 앱은 그대로 동작합니다(이때는 아이콘·매니페스트만 적용되지 않습니다).

## 일기 첨삭 받기

한 줄 일기 카드·일기 작성 시트·지난 일기 목록에 있는 **📋 첨삭용으로 복사** 버튼을 누르면 아래 형식으로 클립보드에 담깁니다. 채팅창에 붙여넣으면 그대로 첨삭을 받을 수 있어요.

```
[일본어 일기 첨삭 부탁해요]
날짜: 2026-11-17 (🙂 ☀️)
일본어: 日本語を勉強しました。
한국어 메모: 오늘은 일본어를 공부했어요
```

한국어 메모가 비어 있으면 그 줄은 빠지고, 일본어 일기가 비어 있으면 먼저 입력해 달라는 안내가 뜹니다.

## 음성

일본어 발음은 브라우저의 Web Speech API(`ja-JP`)를 사용합니다. 기기에 일본어 음성이 없으면 재생되지 않을 수 있으며, 그 경우 안드로이드 설정 → 언어 → 텍스트 음성 변환에서 일본어 음성을 설치하면 됩니다.
