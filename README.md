# withかっちゃん — JLPT N5 · 한 줄 일기

정세온 님을 위한 일본어 공부 웹앱 **withかっちゃん**입니다. 외부 라이브러리나 CDN 없이 `index.html` 한 파일로 동작하고, 학습 기록은 브라우저 `localStorage`에 저장됩니다.

색은 라이트그레이 배경(`#F3F4F6`) + 순백 카드 + 레드 강조색(`#DC2626`, 틴트 `#FEF2F2`/`#FEE2E2`)입니다. 뜻이 있는 색은 그대로 둡니다 — 체중 감소·퀴즈 정답·목표 달성 배지는 초록(`#15803D`), 목표 초과·부족은 앰버(`#B45309`), 주간 체중 그래프는 줄었어요=초록 / 늘었어요=빨강.

### 갤럭시 폴드 · 넓은 화면

접은 커버 화면(`< 600px`, 폴드 커버 280px 포함)은 기존 1열 모바일 화면 그대로입니다. 펼친 메인 화면(`≥ 600px`)에서는 앱 폭이 **840px**까지 넓어지고 내용이 2단으로 펼쳐집니다 — 홈은 바쿠고 메이트를 전체 폭 배너로 두고 루틴·식단 / 운동·일본어 카드를 2열 그리드로, 냉장고는 전체 폭으로 놓습니다. 루틴(데일리 루틴+무드 / 운동+자세한 일기), 식단(목표·수분 / 끼니), 공부(학습·일기 / 단어·회화 · JLPT 로드맵은 로드맵 / 매일 공부량 체크), 냉장고(보관함 2열)도 2단으로 배치되고, 바텀시트는 가운데 정렬 모달(`max-width: 520px`)로 뜹니다.

## 스터디 메이트

`홈`·`루틴` 탭에 《나의 히어로 아카데미아》 爆豪勝己(바쿠고 카츠키)가 함께 공부하는 카드가 나옵니다. 대사는 상황별 풀 13개·242개 문장(아침 / 점심 / 저녁 / 밤 / 새벽 0~4시, 루틴 시작 전·진행 중·완료, 식단 진행, 운동 완료, 일본어 공부, 주말 집안일, 일반 응원)에서 **그때 상황에 맞는 풀을 골라** 한 줄을 보여 줍니다. 재택·야근, 2027.07 JLPT N3(단어·한자·일본어 일기), 1,200kcal·단백질 75~85g, 물 500mL씩, 5~10분 홈트(어깨·허리·발목은 무리 금지), 레오 산책, 주말 빨래·설거지·분리수거, 밤늦게 깨어 있을 때 같은 세온 님의 실제 맥락을 대사에 담았습니다. 모든 대사는 일본어 원문 + 후리가나 읽기 + 한국어 뜻 세 줄로 나옵니다. 고르는 방식은 **상황별 셔플백(shuffle bag)** 입니다. 한 상황의 대사를 무작위 순서로 하나씩 다 보여 준 뒤에야 그 상황의 풀을 리셋하고, 한 바퀴가 끝날 때 방금 본 대사는 새 바퀴의 첫 줄이 아니라 마지막에 나와 연달아 반복되지 않습니다. 남은 대사는 `localStorage`(`nihongo-bakugo-bag-v1`)에 저장되어 앱을 새로 열거나 탭을 옮겨도 이어서 돌고, 대사를 추가·삭제해 개수가 달라져도 저장된 인덱스는 범위 안에서 자동 보정됩니다. 일본어 대사는 🔊로 들을 수 있습니다.
이미지는 저장소 안 `assets/bakugo-1~58.jpg`(세로 300×400, 58장)에 두어 외부 링크 없이(오프라인에서도) 표시됩니다. **사진을 더 넣으려면** `assets/`에 파일을 올리고 `index.html`의 `BAKUGO_IMAGES` 배열에 한 줄, `sw.js`의 `ASSETS`에 같은 경로 한 줄만 더하면 다음 새로고침부터 로테이션에 들어갑니다. **페이지를 열 때마다 다른 사진**으로 시작하고, `다른 한마디 ›`나 카드 사진을 누르면 대사와 사진이 함께 바뀝니다. 원본: 사용자가 직접 보내준 《나의 히어로 아카데미아》 爆豪勝己(바쿠고 카츠키) 공식 일러스트·애니 컷 60장에서 중복(같은 컷) 2장을 빼고 58장을 300×400 세로로 잘라 담았습니다(TVアニメ『僕のヒーローアカデミア』 ©堀越耕平／集英社・僕のヒーローアカデミア製作委員会). — 개인 학습용으로만 사용하세요.

## 홈 화면에 추가 (안드로이드 크롬)

1. 크롬에서 이 페이지를 엽니다.
2. 오른쪽 위 ⋮ → **홈 화면에 추가**.
3. 아이콘을 누르면 주소창 없이 앱처럼 전체 화면으로 열립니다.

`manifest.json`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`가 함께 배포되어 아이콘과 전체 화면 표시에 쓰입니다.

### 앱 아이콘 (바쿠독)

앱 아이콘은 바쿠독(Bakudog) 얼굴 — 크림빛 배경, 분홍 안감의 접힌 뾰족 귀, 주황 눈과 흰 빛망울, 까만 코, 빨간 입 안의 뾰족한 흰 이빨 — 그림 한 장(정사각 1269×1240 JPEG)을 그대로 쓴 것입니다. 벡터(`icon.svg`)는 더 쓰지 않고 아래 PNG 네 장이 모두 같은 원본 그림입니다.

- `icon-512.png` / `icon-192.png` — 원본을 정사각으로 가운데 잘라 512·192로 줄인 판(LANCZOS). `any` 아이콘.
- `icon-maskable-512.png` — 같은 그림을 80%로 줄이고 사방 10%를 원본 배경색(#FCE2A5) 여백으로 채워, 안드로이드 적응형 마스크(원형·스퀘어클) 안전 영역 안에 귀·입이 들어오게 한 판.
- `apple-touch-icon.png` — iOS가 모서리를 직접 자르므로 꽉 찬 사각형 180×180.
- 파비콘(`<link rel="icon">`)도 위 PNG를 가리킵니다.
- 아이콘을 바꾸려면 원본 그림에서 같은 이름의 PNG를 다시 만들어 올리고 `sw.js`의 `CACHE` 버전을 올려 주세요(홈 화면 아이콘은 한동안 캐시됩니다).
`index.html`만 따로 내려받아 파일로 열어도 앱은 그대로 동작합니다(이때는 아이콘·매니페스트만 적용되지 않습니다).

## 냉장고 (채팅 → 앱 반영)

`냉장고` 탭은 집에 있는 식재료를 보관 위치(❄️ 냉장 / 🧊 냉동 / 🍎 실온)별로 보여주고, 앱에서 직접 **추가·수정·소진(다 씀)** 할 수 있는 화면입니다.

- 유통기한을 넣으면 `D-3` 이하·지난 재료를 색으로 강조하고, 목록은 보관 위치 → 유통기한 순으로 정렬됩니다.
- `🔄 최신 목록 동기화` 버튼을 누르면 저장소의 `fridge-data.json`을 다시 받아 목록을 맞춥니다.
- 채팅으로 재료를 알려주면 피클이 `fridge-data.json`의 `version`을 올려 커밋합니다. 앱은 그 버전이 로컬(`localStorage`의 `fridge_seed_version`)보다 높을 때 새 목록을 반영합니다. 서비스 워커는 이 파일만 **network-first**로 받아 새 목록이 바로 적용됩니다.
- 앱에서 직접 넣은 재료와 사용자가 고친 값(수량·유통기한·메모)은 동기화해도 보존됩니다. `다 씀`으로 표시한 재료는 동기화해도 다 쓴 상태로 남고, 다시 사 왔을 때는 동그라미를 한 번 눌러 되돌리면 됩니다.
- 재료 이름 옆 일본어(예: `卵 (たまご)`)와 아래 `식재료 일본어` 카드로 단어도 같이 익힐 수 있습니다.

### `fridge-data.json` 형식

```json
{
  "version": 2,
  "updatedAt": "2026-11-18",
  "items": [
    { "id": "egg", "name": "계란", "jp": "卵", "kana": "たまご", "place": "fridge", "qty": "10개", "expires": "2026-11-25", "memo": "2층 칸" }
  ]
}
```

`place`는 `fridge`(냉장) / `freezer`(냉동) / `room`(실온) 중 하나입니다. `id`는 같은 재료에 같은 값을 유지해 주세요 — 같으면 그 사이에 고친 수량·메모를 살리며 갱신합니다.

`nutri`는 **1회분 기준 영양성분**으로, 아래 `✨ 지금 냉장고로 뭐 먹지?` 추천에 쓰입니다. `unit`은 수량을 셀 때 쓰는 단위(`팩`·`알`·`봉`·`묶음`)이고, `est: true`는 추정치입니다. `nutri`가 없는 재료는 이름으로 영양성분을 짐작하므로(예: `두유`, `계란`, `닭가슴살`) 직접 넣은 재료도 추천에 들어갑니다.

`always: true`는 **상시 구비 품목**입니다(예: `냉동 닭가슴살(현미크런치 등)`·`냉동 닭안심살(오븐구이/청양바베큐 등)`). 수량을 세지 않고 ∞ 배지로 표시하며, `다 씀` 표시가 막히고 `🍽️ 이거 먹었음`을 눌러도 재고가 줄거나 품절되지 않습니다. 예전에 따로 수량 관리하던 현미크런치·오븐구이 항목은 목록을 받을 때 상시 품목으로 합쳐집니다.

## 🥗 식단·수분 기록 (채팅 → 앱 반영)

`루틴` 탭 상단의 **📋 루틴 | 🥗 식단** 전환으로 들어가는 화면입니다. `홈` 탭에는 오늘 섭취 칼로리·단백질·물만 미니 게이지로 보여주고, `+500mL`를 홈에서 바로 누를 수 있으며 `식단 기록 ›`로 이 화면에 들어옵니다.

- 날짜 이동(‹ ›, `오늘로`)으로 하루씩 넘겨 봅니다.
- 목표 대비 진행바 — 칼로리(1,200kcal), 탄수화물(70~100g), 단백질(75~85g), 지방(35~45g). 범위 목표는 띠로 표시되고 `남은 양` / `더 필요` / `많아요`로 알려줍니다.
- 수분은 `500mL 버튼`(`-500` / `+500`)으로 조절하고, 몇 잔인지 함께 보여줍니다.
- 끼니별(🌅 아침 · 🍚 점심 · 🌙 저녁 · 🍪 간식) 음식 목록에서 **추가·수정·삭제**가 됩니다. 눈대중으로 적은 값은 `추정` 배지로 구분합니다.
- 채팅으로 식단을 알려주면 피클이 `diet-data.json`의 `version`을 올려 커밋합니다. 앱은 그 버전이 로컬(`localStorage`의 `diet_seed_version`)보다 높을 때 새 기록을 반영하고, `🔄 최신 식단 동기화`로 직접 받을 수도 있습니다. 서비스 워커는 이 파일을 **network-first**로 받습니다.
- **앱에서 고친 날짜는 보존됩니다.** 그 날의 물·음식은 그대로 두고, 채팅에서 새로 온 항목만 곁들여 더합니다(같은 `id`는 중복되지 않고, 앱에서 지운 항목은 되살리지 않습니다).
- 식단 기록도 복습 탭의 **JSON 백업**에 함께 담깁니다.

```json

  "updatedAt": "2026-11-17",
  "goals": { "calories": 1200, "carbs": [70, 100], "protein": [75, 85], "fat": [35, 45], "waterStepMl": 500 },
  "days": {

`meals`의 키는 `breakfast` / `lunch` / `dinner` / `snack`이고, `kcal`·`carb`·`protein`·`fat`은 g 단위 숫자입니다. `est: true`는 추정치(눈대중)로 표시됩니다. `id`는 같은 음식에 같은 값을 유지해 주세요 — 같으면 앱에서 고친 흔적과 부딪히지 않습니다.

## ✨ 지금 냉장고로 뭐 먹지? (냉장고 × 남은 칼로리)

`식단` 화면 맨 위와 `홈` 식단 카드의 **✨ 지금 냉장고로 뭐 먹지?** 버튼에서, 오늘 **남은 칼로리(1,200 − 섭취)** 안에서 냉장고에 실제로 있는 재료만 골라 **한 끼 기준(300~450kcal)** 조합을 제안합니다.

- 하루 남은 칼로리가 넉넉해도(예: 아침 전 1,200kcal) 한 끼에 하루치를 몰아 담지 않습니다. **1끼 목표 = min(450, 남은 칼로리)kcal**, **단백질 = min(30, max(15, 남은 단백질))g**을 기준으로, 그 범위 안에 들어오는 조합을 먼저 고릅니다.
- 남은 칼로리가 300kcal 미만이면(예: 저녁 이후) 그 남은 칼로리 안에 쏙 들어오는 **가벼운 한 끼·간식(100~남은 kcal)** 을 권합니다.
- 재료를 역할별로 아무렇게나 섞지 않고, **실제로 같이 먹는 식사 모양(meal archetype)** 안에서만 조합합니다. ① **한식 밥상** — 밥(햇반 발아현미밥) + 단백질(닭가슴살·닭안심·계란·두부·새우·오징어) + 밥에만 어울리는 곁들임(간장계란밥소스·조미김·김치, **밥이 있을 때만**) ② **냉동 볶음밥** — 볶음밥(소불고기·곤드레) 하나 + 닭가슴살·계란·두부 또는 매일두유 ③ **피타 샌드위치** — 피타브레드 + 닭가슴살·계란·참치·치즈(+채소, 있을 때만) ④ **가벼운 한 끼·단백질 보충** — 단백한끼·매일두유 + 가벼운 단품(계란·닭안심·고구마·과일). 피타·볶음밥에 간장계란밥소스·조미김을 붙이거나, 밥과 볶음밥·피타를 한 접시에 섞는 조합은 아예 만들지 않습니다. 300~450kcal 범위 안이면 칼로리 차이보다 구성·단백질로 순서를 정합니다.
- 카드 상단에 **한 끼 기준 추천(300~450kcal · 남은 여유 안에서)** 안내가, 각 조합에는 **식사 모양(한식 밥상·냉동 볶음밥·피타 샌드위치·가벼운 단백질 보충)** 과 한 끼 목표 대비 칼로리·단백질이 표시됩니다. `🔄 다른 조합`으로 다른 후보를 볼 수 있습니다.
- **`🍽️ 이거 먹었음`** 을 누르면 그 조합이 **지금 시각의 끼니**(아침/점심/저녁/간식)에 자동으로 들어가고, `10팩`·`15알`처럼 숫자로 관리되는 재료는 **수량도 함께 줄어듭니다**(0이 되면 `다 씀` 처리). `홈`의 오늘 식단 게이지와 남은 칼로리도 바로 갱신됩니다.
- 남은 칼로리가 0이거나 너무 적으면 조합 대신 안내 문구만 보여줍니다(없는 조합을 지어내지 않습니다).

## 💉 마운자로 · 체중·인바디 주간 추세

`루틴` 탭 상단의 **⚖️ 체중** 서브탭입니다. 하루 수치가 아니라 **주간 평균 추세**로 보는 기준을 따릅니다.

- 최근 체중, 시작(91.2kg, 2026-07-21) 대비 총 감량, 목표(58kg)까지 남은 체중, BMI, 이번 주 평균과 지난주 대비 변화를 한 카드에 보여줍니다.
- **주간 평균 체중 SVG 라인 차트 + 전주 대비 막대**(아래로 = 감소, 위로 = 증가). 오른쪽 위 버튼으로 `최근 12주 / 전체`를 바꿉니다.
- 인바디(체지방률·체지방량·골격근량·내장지방지수)와 마운자로 용량 이력(2.5mg 3회 → 8/19 5mg).
- **`＋ 기록 추가`** 로 날짜·체중·체지방률·골격근량·허리둘레·주사 용량을 직접 넣을 수 있고, 최근 기록에서 `✎`로 고칩니다.
- 채팅으로 알려주면 피클이 `weight-data.json`의 `version`을 올려 커밋하고, 앱은 `🔄 최신 기록 동기화`로 받습니다. 앱에서 직접 넣은 날짜 기록은 동기화해도 보존됩니다.
- `홈` 식단 카드 아래에 `⚖️ 84.51kg −6.69kg · 목표까지 …` 배지가 붙어 한눈에 보입니다.

## 📖 오늘의 학습 — 누적 학습량 기반 출제

`공부` 탭 › **📖 오늘의 학습**의 하루치(단어 15개 · 핵심 문법 2개 · 맞춤 문제 10개)는 `study-curriculum.json`의 **일차(days)** 로 정해집니다.

- **일차 = 목표를 다 채운 학습일 수 + 1.** 달력 날짜가 아니라 실제로 끝낸 날을 세므로, 처음 시작한 날은 언제나 **1일차**입니다. 하루 안에서는 일차가 바뀌지 않고, 그날 목표(단어·문법 체크 + 문제 10개)를 다 채우면 다음 날 일차가 하나 올라갑니다.
- **문제는 그 일차까지 배운 누적 범위에서만 나옵니다.** 1일차는 1일차 단어 15개·문법 2개만으로 10문제를 만들고, 2일차부터는 새 단어·문법 위주 7문제 + 이전 일차 복습 3문제입니다. 보기(오답)도 배운 범위 안에서만 고릅니다.
- 문제 섹션 위에 `누적 N일차 기준 · 배운 단어 X개 · 문법 Y개에서 출제`가 표시되고, 해설 아래에는 그 문제가 어느 일차의 무엇을 묻는지(`출처: 2일차 단어 水`)가 붙습니다.
- N5는 명사문·기본 조사(は·を)부터 난이도순으로 10일에 나눴고(단어 150개·문법 22개), N4·N3도 단어 15개·문법 2~3개씩 10일로 나눴습니다. 일차별 단어는 그날의 문법과 어울리는 주제로 묶었습니다(예: 1일차 사람·기초 사물, 2일차 숫자·날짜).
- 모든 문법 포인트에는 전용 문항이 **3개씩**(문법 2 + 문장완성 1) 붙어 있어 어느 일차든 10문제가 겹치거나 비지 않습니다.

      "words": [{ "id": "n5w001", "jp": "一", "kana": "いち", "ko": "하나 (1)", "cat": "숫자", "ex": "...", "exKo": "..." }],
      "grammar": [{ "id": "n5g01", "key": "は", "title": "주제 조사 は", "tag": "...", "sum": "...", "ex": [] }],
      "questions": [{ "id": "n5-g01-p001", "kind": "bunpo", "target": { "t": "g", "id": "n5g01" }, "prompt": "私（　）学生です。", "options": ["は", "を", "に", "で"], "answer": 0, "exp": "..." }]
    }
  }
}
```

- `kind`: `bunpo`(문법 — 표현 고르기) / `bunsho`(문장완성 — 문맥). 단어 문제(읽기·뜻·일본어로)는 앱이 그 날의 단어와 누적 범위 안의 보기로 만들어 `moji`·`goi`로 씁니다.
- `target`이 그 문제가 시험하는 문법(`t: "g"`)입니다. 이 값이 그 일차까지의 누적 문법에 들어 있을 때만 출제됩니다.

### 단어 탭 카드·퀴즈도 같은 누적 범위

`공부` › **단어**의 카드와 퀴즈도 **📖 오늘의 학습과 같은 누적 범위**를 씁니다.

- 단어 탭 위쪽 필터의 기본값은 **`누적 학습 (N일차 · X개)`**입니다. 그 일차까지 배운 단어만 카드로 넘기고, 퀴즈도 그 단어에서만 나옵니다.
- **오답 보기(선택지)도 같은 누적 범위의 단어**에서 고릅니다. 누적 단어가 4개 미만인 극초반에만 전체 단어로 보기를 채웁니다.
- **`전체 범위`**(기존 131개 전체)와 **`오답만`**으로 바꿔 볼 수 있고, 맞힌 오답은 오답노트에서 빠집니다.
- `복습` 탭의 **📚 누적 학습 플래시카드**는 같은 범위의 단어 + 문법을 한 장씩 회독합니다(1일차 = 단어 15 + 문법 2 = 17장).

## 🔁 오답 집중 플래시카드

`복습` 탭 오답노트 위의 **오답 N장 회독 시작** 버튼으로 들어가는 모드입니다.

- 틀린 **가나·단어·회화 문장·JLPT**만 모아, 앞면에 일본어(한자·단어·문장)를 보여주고 **카드를 누르면 뒷면에 읽기·뜻·예문**이 나옵니다.
- `✓ 알겠음`은 이번 회독에서 빼고, `↻ 다시 볼래요`는 카드를 **맨 뒤로** 보내 남은 카드를 다 본 뒤 한 번 더 만나게 합니다.
- 🔊 발음 듣기, 진행률, 알겠음/다시 볼래요 횟수와 남은 카드 수를 보여주고, 끝나면 요약과 `🔁 다시 시작`이 나옵니다.

## 일기 첨삭 받기

한 줄 일기 카드·일기 작성 시트·지난 일기 목록에 있는 **📋 첨삭용으로 복사** 버튼을 누르면 아래 형식으로 클립보드에 담깁니다. 채팅창에 붙여넣으면 그대로 첨삭을 받을 수 있어요.

```
[일본어 일기 첨삭 부탁해요]
날짜: 2026-11-17 (🙂 ☀️)
일본어: 日本語を勉強しました。
한국어 메모: 오늘은 일본어를 공부했어요
```

한국어 메모가 비어 있으면 그 줄은 빠지고, 일본어 일기가 비어 있으면 먼저 입력해 달라는 안내가 뜹니다.

## 음성

일본어 발음은 브라우저의 Web Speech API(`ja-JP`)를 사용합니다. 음성 목록에서 **남성 일본어 음성**(keita·ichiro·otoya·naoki·hattori·daichi·kenji·takumi·male·man·男 등 이름 패턴)을 최우선으로 고르고, 남성 음성이 없는 기기에서는 `pitch`를 0.85로 낮춰 남성에 가까운 톤으로 재생합니다(남성 음성이 잡힌 경우 `pitch` 0.95). 재생 속도는 앱의 0.75배/1.0배 설정을 그대로 따릅니다. 선택된 음성은 콘솔에서 `jaVoiceInfo()`로 확인할 수 있습니다. 기기에 일본어 음성이 없으면 재생되지 않을 수 있으며, 그 경우 안드로이드 설정 → 언어 → 텍스트 음성 변환에서 일본어 음성을 설치하면 됩니다.
